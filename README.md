# Java-Basics
This will store each file of Java and its most basic code.

This does go into pretty advanced stuff once you get to the Advanced Basics file, but that's because I am following a course on Udemy for my personal use. As part of my college class, I am making a GitHub repository for all of this so that anyone can follow along if they so please to as I make progress throughout the course, which I will be adding to this repository whilst I learn increasingly difficult topics.

By the end of the course, I will make another little repository-thing that will show all my learning hurdles through advanced Java, promptly named 'Java-Advanced', or something of the rather. This is NOT meant to be copied so that things just work. This is meant for people to read any comments I put into the code and then prompting you to try and do the same with your own ideas and your own code. The comments are there for understanding, not placeholders so I can have more data stuck in there.

SIDENOTE: I advise you to read the comments because most of them mainly describe why the syntax is the way it is and not exactly what the code itself is doing.
